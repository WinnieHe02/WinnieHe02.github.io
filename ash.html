Learning Design TempoLink MycoSphere The Ash of a Breath

Interactive Experience Design · 2025

An interactive installation about wildfire loss and recovery. Visitors move among objects that stand for different stages of the fires' aftermath, and blowing on an object plays a story or video from someone who lived through it. The installation asks what small, meaningful actions we can take to support recovery and community healing.

Background

January 2025

My project takes inspiration from the California wildfires of January 2025, when Los Angeles and San Diego counties faced weeks of destructive fires that displaced families, destroyed habitats and made the air unbreathable. As a UCLA student, I lived under smoke-filled skies and the unsettling quiet that followed. Friends were evacuated, and some lost their homes.

The fires killed at least 31 people, with later estimates of up to 440 related deaths.

Reasons behind

California's wildfires are growing more frequent and intense because of climate change, land management practices and urban development. Rising temperatures, long droughts and shifting rainfall have dried out the landscape, so even a small spark can start a huge fire. Climate change alone is linked to about a quarter of the extreme fuel dryness in recent fires, making them larger and more intense than they would otherwise have been.

Process

Observation, research and brainstorm

Three kinds of harm shaped the objects: the loss of wildlife, the health risks people face from toxic smoke, and the trauma communities carry through displacement and long fights with insurers.

Design concept

Three iterations

Pure smoke

The first version worked more like a fine art installation. It lacked interaction: it created atmosphere but couldn't actively communicate anything.

From disaster to reflection

Smoke could be too triggering for some viewers. Instead of emphasizing the disaster itself, the installation should focus on reflection, inviting the audience to think about recovery, resilience, and how to prevent such tragedies in the future.

Breath as the interaction

The installation unfolds in layers, from immediate destruction to long-term recovery. Visitors pick up story-linked objects and blow on them to trigger short videos. The act stands for both how little one person can do to stop a disaster and the meaningful action still possible afterward, inviting reflection on loss, remembrance and collective recovery.

Final outcome

Three layers of objects

01

Burned branches and animals show the most immediate effect: the fire's destruction of the environment.

02

Medical and personal items stand for the long-term effects on people's lives. A mask, a cane and burned clothes carry the lasting damage of survival.

03

Pills, photo frames and burned letters: fragments of psychological pain that call for remembrance and rebuilding.

Build

Technical support

Each object hides a breath sensor wired to an Arduino. When the sensor detects a breath, it sends a signal to a Processing sketch that plays the matching video.

Hardware loop

  1. The sensor picks up a breath
  2. checked every 10, 5 or 3 s
  3. The Arduino loop detects it and sends “e” over serial
  4. Processing watches the serial port and receives “e”
  5. Play the matching video
  6. No signal: keep sensing

Visitor flow

  1. The visitor arrives at the installation
  2. Views and touches different objects
  3. Reads how the interaction works
  4. 20 s later
  5. Starts blowing
  6. The sensor senses the airflow
  7. 2 s later
  8. The video plays for at least 30 s
const int sensorPin = 2;

void setup() {
  Serial.begin(9600);
  pinMode(sensorPin, INPUT);
}

void loop() {
  int sensorState = digitalRead(sensorPin);

  if (sensorState == LOW) {
    Serial.write('e');
    delay(500);
  }
  delay(100);
}
import processing.serial.*;
import processing.video.*;

Serial myPort;
Movie myMovie;

void setup() {
  size(1280, 720);
  background(0);
  String portName = "COM3";
  myPort = new Serial(this, portName, 9600);
  myMovie = new Movie(this, "my_video.mp4");
}

void draw() {
  while (myPort.available() > 0) {
    char inChar = myPort.readChar();
    if (inChar == 'e') {
      if (myMovie != null) {
        myMovie.play();
      }
    }
  }
  if (myMovie.available()) {
    myMovie.read();
  }
  image(myMovie, 0, 0, width, height);
}

void movieEvent(Movie m) {
  m.stop();
}
